# DuePulse

A smart assignment planner for Canvas LMS users. DuePulse syncs your assignments, learns your productive patterns, and sends AI-generated push notifications—no noise.

## Features

- **Canvas Integration** — Automatic sync of assignments and due dates
- **Productivity Insights** — Learns when you're most productive over time
- **AI Nudges** — Personalized push notifications generated by NVIDIA NIM
- **Workload Visualization** — D3-based heatmaps and charts
- **Progressive Web App** — Installable, works offline

## Architecture

```
Canvas API → Supabase → Trigger.dev (Hourly Jobs) → Web Push
                ↓
         D3 Dashboard
```

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript (strict) |
| Styling | Tailwind CSS 4 + shadcn/ui |
| Database | Supabase (PostgreSQL + Auth) |
| Charts | D3.js |
| AI | NVIDIA NIM (Mistral Large) |
| Notifications | Web Push API |
| State | Zustand |
| Jobs | Trigger.dev |
| Cache | Upstash Redis |

## Environment Setup

Requires: Supabase project, Canvas developer token, NVIDIA NIM API key, VAPID keys, Upstash Redis, Trigger.dev account.

See `supabase/schema.sql` for database setup.
